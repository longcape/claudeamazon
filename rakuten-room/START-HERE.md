# はじめに読む — 操作マニュアル

ターミナルやコマンドの知識は不要です。
**やることは「Claudeに日本語で頼む」だけ**で、コマンドはすべてClaudeが実行します。

このファイルは「あなたが手を動かす部分」だけを扱います。
仕組みの説明は `README.md`、経緯と技術メモは `HANDOFF.md` にあります。

---

## 準備（初日だけ・30分ほど）

### ステップ1 — 楽天のアプリIDを取る

商品データを取るための鍵です。無料で、その場で発行されます。

1. <https://webservice.rakuten.co.jp/> を開く
2. 右上から**楽天会員IDでログイン**する（普段の楽天の会員IDでOK）
3. 「アプリID発行」または「アプリID/デベロッパーID発行」のページへ進む
4. アプリ情報を入力する
   - **アプリ名** — 何でも構いません（例: `room-tool`）
   - **アプリURL** — 自分のサイトが無ければ、楽天ROOMのマイページURLでOK
5. 発行された **アプリID（applicationId）** をコピーする
   - 20桁くらいの数字の羅列です

画面の文言が違っていても慌てなくて大丈夫です。**Claudeに「この画面でどこを押せばいい？」と聞けば案内してくれます。**

### ステップ2 — 楽天アフィリエイトIDを確認する

報酬を受け取るための鍵です。楽天ROOMを使っているなら、すでに発行されています。

1. <https://affiliate.rakuten.co.jp/> にログイン
2. アフィリエイトIDを確認する
   - `1a2b3c4d.5e6f7g8h.9i0j1k2l.3m4n5o6p` のような、ピリオド区切りの文字列です
3. コピーする

ステップ1の楽天ウェブサービスのアプリ管理画面にも表示されていることがあります。

### ステップ3 — Claudeに渡す

2つのIDをコピーしたら、Claude Codeにこう頼みます。

```
楽天のIDが取れました。.env に設定してください。
アプリID: （ここに貼る）
アフィリエイトID: （ここに貼る）

設定したら doctor と probe を実行して、問題がないか教えてください。
```

`.env` はパソコンの中だけに保存され、GitHubには上がりません。

### ステップ4 — 扱う商材を決める

**ここだけは、あなたにしか決められません。**

初期設定は「インテリア・寝具・収納」のサンプルが入っています。
自分が扱いたいジャンルに変えます。

```
私が扱いたいのは「（例: キッチン用品 / 美容グッズ / ペット用品）」です。
config/strategy.json をこれに合わせて書き換えてください。
キーワードの候補も一緒に提案してください。
```

まだ決まっていなければ、そう言えば一緒に決められます。

```
どのジャンルにするか決まっていません。
楽天市場のジャンル一覧を見ながら、一緒に決めたいです。
```

## 毎日の運用

### 1〜2日目 — データを貯めるだけ

```
今日のぶんの候補を集めてください。
```

売上の勢いは「レビュー件数が昨日から何件増えたか」で測ります。
そのため**初日は比較する相手がおらず、精度が出ません。**
2〜3日は集めるだけにしてください。焦らないことが結果的に一番の近道です。

### 3日目 — 最初の30件を作る

```
初動の30件を組んでください。
```

楽天ROOMのアルゴリズムは**最初の30件を極端に重く評価**します。
ここだけは急がず、データが貯まってから組んでください。

できあがると `out/` フォルダに投稿台本が出ます。中身はこうなっています。

```
### 1. 20:05　[評価取り]　1,980円
**商品**: シンク下 収納ラック 伸縮 2段
**リンク**: https://hb.afl.rakuten.co.jp/...

**投稿文（このまま貼る）**
狭いキッチンで戦っている人へ。シンク下のデッドスペースが、
伸ばして合わせるだけで収納に変わる。
#キッチン収納 #暮らしの整え方
```

**この投稿文とリンクを、楽天ROOMにそのまま貼るだけ**です。

### 投稿するとき

```
そろそろ投稿の時間ですか？次に出すものを見せてください。
```

貼り終えたら報告します。

```
1番と2番を投稿しました。
```

### 4日目以降

```
今日の投稿計画を作ってください。
```

### 週に1回 — 結果を教える

楽天ROOMとアフィリエイトの管理画面で数字を見て、そのまま伝えます。

```
先週の実績です。
1番: いいね24、クリック61、成約2件、売上4980円
2番: いいね12、クリック18、成約0件
```

```
これまでの成績を見せてください。
```

**これが効きます。** 実績が6件を超えると、
どのジャンル・価格帯・時間帯が当たっているかを学習して、次の選定に反映します。

## 覚えておく3つのこと

### 1. ゴールデンタイムは20時〜23時

投稿計画はこの時間に自動で寄せられます。**この時間に貼れる日を選んで**計画を作ってください。

### 2. 評価取り → 売上 の順番を崩さない

台本の順番には意味があります。
「評価取り」で見てもらってから「売上」を出すと成約率が上がる、という設計です。
**順番を入れ替えたり、売上投稿だけ抜き出して投稿しないでください。** 効果が落ちます。

### 3. data フォルダを消さない

`data` フォルダには、売上の勢いの記録と「どの商品をもう投稿したか」の履歴が入っています。
消すと**同じ商品を二度投稿してしまいます**。

心配なら、月に一度こう頼んでください。

```
data フォルダをバックアップしてください。
```

## 困ったときの頼み方

そのまま貼れば通じます。

| 状況 | 言い方 |
| --- | --- |
| エラーが出た | `こんなエラーが出ました。（画面をコピーして貼る）どうすればいいですか？` |
| 何をすればいいか分からない | `いまどういう状態ですか？次に何をすればいいですか？` |
| 投稿文がしっくりこない | `out の台本を10件読んで、文が商品と合っているか見てください` |
| 商品がイマイチ | `選ばれた商品の質が低い気がします。原因を調べてください` |
| 成果が出ない | `これまでの実績を分析して、何を変えるべきか教えてください` |
| 用語が分からない | `「評価取り投稿」ってどういう意味ですか？` |

**分からないことは全部Claudeに聞いて構いません。** それが一番速い方法です。
