# いま何をすればいいか（2026-09-02 時点）

**あなたがやることは3つだけです。コマンドは打たなくて構いません。**

## 1. まず最初の12投稿の実験をやります

エンジンが「何を・何時に・どの順で出すか」を12件ぶん決めています。
あなたは**貼り付けるだけ**です。

- 4日間、1日3投稿
- 2日は **21:10 / 21:30 / 21:50**
- 2日は **翌0:10 / 0:30 / 0:50**
- どちらの時間帯も「評価取り2・売上2・送客2」で同じ構成にしてあります

**時間帯をずらさないでください。** 時間帯の効果を測る実験なので、
時刻が動くと何が効いたのか分からなくなります。

## 2. 投稿したら数字を教えてください

投稿から**24時間たってから**、次の3つを見てください。

- その投稿の **いいね数**
- **楽天市場へ飛んだクリック数**（楽天アフィリエイトのレポート）
- 分かれば **クリックした人数**（ユニーク）

チャットでそのまま伝えてください。記録はこちらで行います。

## 3. 成約は「まだ0」でも気にしないでください

楽天アフィリエイトの成果は、**クリックから最大89日後**まで発生します。
投稿した直後に成約0なのは、失敗ではなく**まだ観測期間が来ていないだけ**です。

エンジンは30日たっていない投稿の成約を学習に使いません。
焦って商品を入れ替えないでください。

---

## いつ何が分かるか

| 時期 | 分かること |
| --- | --- |
| 投稿24時間後 | クリックの多い少ない |
| 7日後 | 早期の成約（参考値） |
| 30日後 | 成約を学習に使い始める |
| 各時間帯12投稿ずつ | どちらの時間帯が良いかを判定できる |
| 89日後 | 最終的な成果が確定する |

**12投稿では時間帯の勝敗は決まりません。** 最初の実験は「比べられる形を作る」ためのものです。
2回目の実験では時間帯を入れ替えて、同じ条件で比べます。

---

## エンジンがやらないこと（あなたが手でやること）

楽天ROOMのランクは、投稿だけでは上がりません。次は**自動化しません**。
規約上のリスクがあるのと、アカウントを失う損失に見合わないためです。

無理のない範囲で、思い出したときにやってください。**毎日ノルマにしないでください。**

| やること | 目安 | なぜ |
| --- | --- | --- |
| 楽天市場で検索・買い物をする | ふだんの買い物でよい | ランクの条件に入っています |
| 気になったROOMをフォローする | 1日数件 | 同上。数を稼ぐ操作はしない |
| いいねを押す | 見て良いと思ったものだけ | 大量に押すツールは使わない |
| **オリジナル写真を投稿する** | 撮れるときだけ | **ランク上とくに重要とされています** |
| 楽天市場へ誘導する | 投稿がその役割 | ランクの条件に入っています |

### オリジナル写真について

**自分が実際に買った物・持っている物なら、写真を撮れます。**
借り物の画像より強く、実際に使った感想も書けます。

いま12投稿の実験に入っている商品のうち、**すでに持っている物があれば教えてください。**
その投稿だけ写真付きに差し替えられます。

まだ何も持っていない場合は、実験を優先してください。写真は後からでも足せます。


---

## やってはいけないこと

- 投稿時刻を勝手にずらす（実験が測れなくなります）
- 成約が0だからといって商品を入れ替える（観測期間が来ていないだけです）
- 1日に4件以上投稿する（乱立を避けるため1日3件までです）
- 自動投稿ツールや大量フォローを使う（規約リスクがあります）

## ステップ5 — 楽天のIDを2つ取る

ブラウザでの作業です。無料で、その場で発行されます。

### ① アプリID（商品データを取るための鍵）

1. <https://webservice.rakuten.co.jp/> を開く
2. 右上から**楽天会員IDでログイン**（普段の楽天のIDでOK）
3. 「アプリID発行」のページへ進む
4. アプリ名（`room-tool` など何でも可）とアプリURL
   （自分のサイトが無ければ楽天ROOMのマイページURLでOK）を入力
5. 発行された **アプリID** をコピー（20桁くらいの数字）

### ② アフィリエイトID（報酬を受け取るための鍵）

1. <https://affiliate.rakuten.co.jp/> にログイン
2. アフィリエイトIDを確認してコピー
   （`1a2b3c4d.5e6f7g8h.9i0j1k2l.3m4n5o6p` のようなピリオド区切りの文字列）

楽天ROOMを使っているなら、すでに発行されています。
①の管理画面に一緒に表示されていることもあります。

> 画面の文言が違っていても慌てなくて大丈夫です。
> **Claudeに「この画面のどこを押せばいい？」と聞けば案内してくれます。**

### ③ Claudeに渡す

```
楽天のIDが取れました。.env に設定してください。
アプリID: （ここに貼る）
アフィリエイトID: （ここに貼る）

設定したら doctor と probe を実行して、問題がないか教えてください。
```

`.env` はパソコンの中だけに保存され、GitHubには上がりません。

**✅ 確認** — probe の結果で、全項目に `○` が付いている

`×` や `△` が出たら、**そのまま先へ進まないでください。**
その項目に対応する判断材料が機能していない状態です。Claudeに原因を調べさせてください。

# 第2部 — 毎日の運用

## 1〜2日目 — 集めるだけ

```
今日のぶんの候補を集めてください。
```

売上の勢いは「レビュー件数が昨日から何件増えたか」で測ります。
そのため**初日は比較する相手がおらず、精度が出ません。**
2〜3日は集めるだけにしてください。焦らないことが結果的に一番の近道です。

## 3日目 — 最初の30件を作る

```
初動の30件を組んでください。
```

楽天ROOMのアルゴリズムは**最初の30件を極端に重く評価**します。
ここだけは急がず、データが貯まってから組んでください。

できあがると `out` フォルダに投稿台本が出ます。中身はこうなっています。

```
### 1. 20:05　[評価取り]　1,980円
**商品**: シンク下 収納ラック 伸縮 2段
**リンク**: https://hb.afl.rakuten.co.jp/...

**投稿文（このまま貼る）**
狭いキッチンで戦っている人へ。シンク下のデッドスペースが、
伸ばして合わせるだけで収納に変わる。
#キッチン収納 #暮らしの整え方
```

**この投稿文とリンクを、楽天ROOMにそのまま貼るだけ**です。

## 投稿するとき

```
そろそろ投稿の時間ですか？次に出すものを見せてください。
```

貼り終えたら報告します。

```
1番と2番を投稿しました。
```

## 4日目以降

```
今日の投稿計画を作ってください。
```

## 週に1回 — 結果を教える

楽天ROOMとアフィリエイトの管理画面で数字を見て、そのまま伝えます。

```
先週の実績です。
1番: いいね24、クリック61、成約2件、売上4980円
2番: いいね12、クリック18、成約0件
```

```
これまでの成績を見せてください。
```

**これが効きます。** 実績が6件を超えると、
どのジャンル・価格帯・時間帯が当たっているかを学習して、次の選定に反映します。

# 第3部 — 守ってほしい3つ

### 1. ゴールデンタイムは20時〜23時

投稿計画はこの時間に自動で寄せられます。**この時間に貼れる日を選んで**計画を作ってください。

### 2. 台本の順番を崩さない

「評価取り → 売上」の並びには意味があります。
評価取りで見てもらってから売上を出すと成約率が上がる、という設計です。
**順番を入れ替えたり、売上投稿だけ抜き出して投稿しないでください。** 効果が落ちます。

### 3. `data` フォルダを消さない

売上の勢いの記録と、「どの商品をもう投稿したか」の履歴が入っています。
消すと**同じ商品を二度投稿してしまいます**。

月に一度、こう頼んでください。

```
data フォルダをバックアップしてください。
```

# 第4部 — 困ったときの頼み方

そのまま貼れば通じます。

| 状況 | 言い方 |
| --- | --- |
| エラーが出た | `こんなエラーが出ました。（画面をコピーして貼る）どうすればいいですか？` |
| 何をすればいいか分からない | `いまどういう状態ですか？次に何をすればいいですか？` |
| 投稿文がしっくりこない | `out の台本を10件読んで、文が商品と合っているか見てください` |
| 商品がイマイチ | `選ばれた商品の質が低い気がします。原因を調べてください` |
| 成果が出ない | `これまでの実績を分析して、何を変えるべきか教えてください` |
| 用語が分からない | `「評価取り投稿」ってどういう意味ですか？` |
| 手順を忘れた | `START-HERE.md を読んで、次に何をすればいいか教えてください` |

**分からないことは全部Claudeに聞いて構いません。** それが一番速い方法です。
手順を暗記する必要はありません。
