# VALORANT TACTICAL SETUP CARD

VALORANT 競技シーン向けの **ラウンド戦術セットアップカード**。
試合前に戦術を登録し、ラウンドの勝敗に応じて次のラウンドの戦術を選び直していく
「戦術コールの管理ツール」です。tracker.gg / valorant.gg のタクティカルボード風のダーク UI。

ビルド不要の静的アプリ（HTML + CSS + Vanilla JS、依存パッケージなし）。
`index.html` をブラウザで開くだけで動きます。

- **相性判定** — 味方と相手のエージェント構成から、その戦術が刺さるかを判定（完全オフライン）
- **配置盤** — マップ上にエージェント・スキル・プラント位置を配置し、進行ルートを矢印で描く。スキルには使用順の番号が付く。1 つの戦術に**局面を最大 4 枚**持てるので、A フェイク → B のような多段の動きも分けて書ける
- **分岐ツリー** — 「この戦術で勝ったら次はこれ、負けたらこれ」をつなぎ、ラウンドの勝敗が付いた時点で次の候補を先頭に出す
- **戦術の検索・グループ分け** — 名前 / メモ / サイトで絞り込み、サイト・種別・サイドでまとめて表示
- **構成プリセット** — 5 人構成を名前を付けて保存（上限 12）。エージェントピッカーは 1 体選ぶと次の空きスロットへ自動で送る
- **公式画像を同梱** — エージェントの顔・スキルアイコン・マップのミニマップ・スパイクを収録済み（計 159 枚）。ミニマップは**ディフェンダー上 / アタッカー下**に向きを揃えてある
- **全 29 エージェント / 全 13 マップ** — ヴィトー（2025/10/08）とミクス（2026/03/19）を含む最新ロスター
- **X へ投稿** — マッチ決着時のバナーから、スコアと戦術別成績をまとめてポスト
- **多言語** — 日本語 / English / 한국어（言語ファイル 1 枚で追加可能）
- **AI 寸評** — Claude が構成を読んで弱点と対策を書く（任意設定）
- **コミュニティ投稿** — 「僕の考えた最強の戦術」を共有・取り込み。通報（同じ人は 1 回まで、5 件で自動的に非表示）と、自分の投稿の編集・削除つき（任意設定）
- **クラウド保存** — 設定と戦績を Supabase に保存（任意設定）

## 使い方

### 01. SETUP — 試合の準備

| 項目 | 内容 |
| --- | --- |
| **MATCH SETUP** | マップ（全 13 マップ）、チーム名、前半のサイド（ATTACK / DEFENSE）、スカウトメモ |
| **AGENT COMPOSITION** | 味方 5 / 敵 5 のエージェントをセット。ロール別フィルタ・検索・プレイヤー名（IGN）付き |
| **TACTIC DECK** | ラウンドで使う戦術を事前登録。戦術名 / 使用サイド / ターゲットサイト / 戦術タイプ / コール詳細 |

味方・敵のエージェントが 5 体ずつ揃い、戦術が 1 つ以上登録されると **START MATCH** が押せます。

### 02. LIVE BOARD — ラウンドループ

```
戦術を選択  →  カードを表示（コール共有）  →  WIN / LOSS を記録  →  次ラウンドの戦術を選択  →  …
```

1. **戦術を選択**
   現在のサイドで使える戦術だけが候補に並び、直前ラウンドの結果をもとに **SCORE（推奨度 0-100）** と
   推奨理由が表示されます。エコノミー（FULL BUY / FORCE / ECO / BONUS）も併せて記録できます。
2. **戦術カード**
   選んだ戦術が大きく表示されます。サイト・戦術タイプ・コール詳細・その戦術の通算成績・連投数が一目で分かります。
3. **WIN / LOSS**
   ラウンド結果を押すと記録され、自動で次ラウンドの戦術選択に戻ります。
   サイドは 13 ラウンド目で自動反転、25 ラウンド目以降（OT）は毎ラウンド交代します（手動反転も可）。

下段には **ROUND TIMELINE**（全ラウンドの戦術と勝敗）と **TACTIC PERFORMANCE**（戦術別勝率）が並びます。

## 配置盤（TACTICAL BOARD）

戦術ごとに、マップ上へエージェントとスキルを配置できます。配置は戦術に紐づいて保存され、
その戦術を選ぶと復元されます。

配置は**局面（フェーズ）ごとに分けられます**（最大 4 枚）。
「A に見せる」「B へ寄せる」を 1 枚のシートに描くと読めなくなるためです。

| できること | 操作 |
| --- | --- |
| エージェントを置く | 左右のパレットで選び、マップをタップ |
| スキルを置く | 同上。スロット（C / Q / E / X）単位で置ける |
| プラント位置を置く | パレットのスパイクを選んでタップ。1 つの盤面に 1 つだけ |
| 位置を動かす | **左ドラッグ** |
| 置いたものを消す | **右クリック**（ルートの線も同じ） |
| 使用順を決める | スキルを置くと自動で採番。選択して「順番を早く / 遅く」で入れ替え |
| 進行ルートを描く | 「ルートを描く」→ マップを順にタップ →「ルート確定」 |

**スキルの使用順**は、オーメンのように同時に 1 つしか展開できないアビリティで効きます。
番号は**エージェントごとに 1 から**振られ、ライブボードにはエージェント別の一覧が出ます。

```
JETT   ① クラウドバースト   ② クラウドバースト   ③ テイルウィンド
OMEN   ① ダークカバー
```

表示サイズは配置盤のツールバーから 5 段階（520 / 660 / 800 / 940 / 1080px）で変更でき、設定は記憶されます。
指定した値は**上限**として働き、画面に入らない大きさにはなりません。

スキルアイコンとアビリティの正式名称は**公式のものを同梱済み**です。
新エージェントの追加などで更新が要るときだけ `tools/fetch-assets.mjs` を実行します
（名称は日本語 / 英語 / 韓国語をまとめて取得します）。

配置盤は **SETUP の戦術カードの「▣ 配置を編集」**、戦術の編集画面、
そして LIVE BOARD の配置盤パネルから開けます。試合前に用意しておけます。

> 同時展開数（チャージ）は表示していません。パッチごとに変わるうえ公式 API では
> 配信されておらず、手書きで持つと必ず古くなるためです（ネオンのリレーボルトは
> パッチ 8.11 で 2 個から 1 個に変更されています）。
> 置いた数と使用順で意図は伝わるため、誤った数を出すより表示しない方を選んでいます。

## 相性判定（MATCHUP ANALYSIS）

戦術を選ぶと、**味方 5 体 × 相手 5 体 × マップ × 戦術タイプ**から相性を判定します。
`刺さる` / `五分` / `刺さらない` の判定と、その根拠が一件ずつ並びます。

エージェントごとに「何ができるか」をタグ（スモーク・フラッシュ・索敵・地点排除・設置物・
機動力・アビリティ無効化など）として持たせ、構成単位で集計してルールに当てています。

例: **ジェット / スカイ / オーメン / キルジョイ / ゲッコー** で
**レイズ / ソーヴァ / ヴァイパー / サイファー / ブリーチ** に B ファストラッシュを仕掛けた場合

```
刺さらない  32/100
  通る根拠   フラッシュ 3 枚で一気に距離を詰められる
  弱点       VIPER の壁で進行を止められる
             相手の設置物 1 個で速攻が止まる
             相手の地点排除 4 枚で、入り口で足を止められる
             相手の定点ユーティリティ 2 枚が設置後に効いてくる
```

判定は**完全にオフラインで動き、通信もコストも発生しません**。実戦中に使うのはこちらです。

## 推奨ロジック（SCORE の出し方）

基準値 50 点に対して、以下を加減算します。

| 条件 | スコア |
| --- | --- |
| 通算勝率 | `(勝率 - 50) × 0.7` |
| 未使用（相手に情報を与えていない） | **+14** |
| 直前ラウンドで成功した戦術 | **+10** |
| 直前ラウンドで失敗した戦術 | **-22** |
| 同じ戦術の連投（n 連投） | **-8 × n** |
| 直近 3 ラウンド以内に使用 | **-6** |
| 6 ラウンド以上使っていない | **+8** |
| 直前が敗北 + ターゲットサイトを変更 | **+7** |
| 直前が敗北 + フェイク / スプリット系 | **+4** |
| サイド不一致（「他サイドも表示」時） | **-30** |

- 連投ペナルティは **2 連投以上**で発動します。
- 「直近 3 ラウンド以内」は、直前ラウンドと**別の**戦術を選ぶ場合にだけ効きます（直前と同じ戦術は上 2 行で処理）。
- ラウンド履歴がまだ無い初回は、勝率データが無いのでスコアを 50 に固定し、
  `execute` / `default` 系だけ +6 して並べます。
- 最終スコアは 0〜100 に丸めます。

「勝った戦術は相手が対応してくるまで回す / 負けた戦術の連投は避ける / 連投は読まれる」という
実戦のセオリーをそのままスコア化しています。**あくまで判断材料**なので、最終的なコールは自由に選べます。

## その他の機能

- **自動保存** — 編成・戦術デッキ・ラウンド履歴は `localStorage` に保存され、リロードしても復元されます
- **戦術の検索・グループ分け** — SETUP の戦術デッキを名前 / メモ / サイトで絞り込み、サイト・種別・サイドでまとめて表示
- **構成プリセット** — 5 人構成に名前を付けて保存（上限 12）。呼び出すとまとめてセットされます
- **直前のラウンドを取り消す** — 押し間違えた結果を 1 つ戻す
- **スコアリセット** — ROUND TIMELINE の「スコアリセット」。編成と戦術デッキを残したままスコアと履歴だけ消します
- **キーボードショートカット** — 戦術カード表示中は `W` = WIN / `L` = LOSS、戦術選択中は `1`〜`9` で候補を選択
- **レスポンシブ** — PC / タブレット / スマホに対応（試合中はスマホでの確認を想定）
- **X へ投稿** — マッチ決着時のバナーから、スコアと戦術別成績をまとめてポスト（API キー不要）。
  ラウンドの途中には出しません。共有する中身がまだ無いためです
- **多言語** — 日本語 / English / 한국어。初回はブラウザの言語設定に自動で合わせます
- **コミュニティ投稿** — 戦術を共有し、他の人の戦術を自分のデッキに取り込めます（要 Supabase 設定）
- **登録数の上限** — `config.js` の `TACTIC_LIMIT_FREE` で設定。0 なら無制限（既定）
- **マッチ決着時** — 勝敗バナーに「新しいマッチを始める」ボタンが出ます

### `⋯` メニュー（画面右上）

書き出し・読み込み・初期化は**めったに使わないうえ、試合中に押し間違えると痛い**ので、
`⋯` メニューへ一段隠してあります。

| 項目 | 内容 |
| --- | --- |
| **書き出し（EXPORT）** | 設定と戦績を JSON で保存。チーム内での共有やマップ別デッキの使い分けに |
| **読み込み（IMPORT）** | 書き出した JSON を読み込む |
| **初期化** | 編成・戦術デッキ・戦績を**すべて**消す。上の「スコアリセット」とは別物 |

登録した戦術は**ブラウザごとの `localStorage`** に入ります。別のブラウザや公開ページ版とは
データを共有しないので、移すときは書き出し → 読み込みを使ってください。

## 起動方法

```bash
# そのまま開く（Windows は index.html をダブルクリック）
open index.html

# もしくは簡易サーバー経由で
npx http-server . -p 8080
# → http://localhost:8080
```

`file://` で直接開いても動きます。そのために **ES モジュールを使わず**、
各ファイルを IIFE で `window.VCT_*` に生やしています（ES モジュールは `file://` では CORS で落ちるため）。

## 配布用ビルド

全ファイルを 1 枚の HTML に束ねます（依存パッケージなし）。

```bash
node build.js
```

| 生成物 | 用途 |
| --- | --- |
| `dist/valorant-tactical-setup-card.html` | スタンドアロン版。このファイル 1 つを配ればよく、ダブルクリックで起動、オフラインでも動作 |
| `dist/artifact-body.html` | 公開ページ発行用（外側の `html` / `head` / `body` は発行側で付与される） |

`⋯` メニューの書き出しは、通常のブラウザでは Blob 経由でダウンロードし、
公開ページ上では閲覧者に確認を出してから保存します（`downloads` capability）。
capability を宣言してもサンドボックス側で落ちることがあるため、Blob + `<a download>` の
フォールバックを残してあります。

## エージェントとマップの画像

**公式画像はリポジトリに同梱済みです**（`assets/img/` に 159 枚）。
clone すればそのままエージェントの顔・スキルアイコン・マップのミニマップ・スパイクが表示されます。
取得の作業は、新エージェントや新マップが来たときだけ必要です。

公式ミニマップはマップごとに向きがばらばらなので、**ディフェンダースポーンが上 / アタッカースポーンが下**に
揃うよう補正角を掛けています（フラクチャーだけは南北の両側から攻めるため 0 度のまま）。

画像が無い場合のフォールバックも残してあります。エージェントは**固有色を割り当てた六角アイコン**
（外周のリングがロール色）、マップは**簡易図**です。ロール色だけだとデュエリスト 8 体が
すべて同じ赤になり見分けられないため、エージェントごとに色を分けています。

### 公式画像を取り直す

Riot の公式アセットを取り込むツールを同梱しています。取得元は valorant-api.com です。

```bash
node tools/fetch-assets.mjs            # 画像ファイルとして保存
node build.js                          # 配布ファイルに反映
```

Windows は `画像を取得.bat`、Mac は `画像を取得.command` をダブルクリックしても同じことができます。
PC で作業したくない場合は **GitHub Actions**（Actions タブ →「公式画像の取得」→ Run workflow）でも実行でき、
取得 → `node build.js` → 変化があればコミット、まで通ります。毎月 1 日にも自動で走ります。

ターミナルの使い方から順を追った手順は **[docs/FETCH-ASSETS.md](docs/FETCH-ASSETS.md)** にまとめてあります。

`assets/js/official-assets.js` が**自動生成**されます（手で編集しないでください）。
このツールは **API 側に存在してアプリに未登録のエージェントも報告する**ので、
新エージェントが追加されたときの取りこぼし検出にも使えます。

`--inline` オプションは画像を data URI として `official-assets.js` に直接埋め込みますが、
**通常は不要**です。`node build.js` が配布用の単一 HTML を作るときに画像を埋め込むためです。

> 無料公開なら事前の申請は不要ですが、指定された免責表記の掲示が条件です（本ファイル末尾を参照）。

## 開発する

```bash
git clone -b claude/valorant-tactical-setup-card-iiiog3 \
  https://github.com/longcape/claudeamazon.git
```

`index.html` をブラウザで開けばそのまま動きます。ビルドは不要です。
`assets/` を触ったら `node build.js` で `dist/` を作り直してください。

```bash
node build.js               # 単一 HTML を作り直す
node tools/smoke-test.mjs   # 動作確認 50 項目
```

smoke-test は初回だけ準備が要ります。

```bash
npm install -D playwright
npx playwright install chromium
```

**`assets/` か `index.html` を触ったら `node build.js` を必ず実行**してからコミットしてください
（`dist/` の作り直し忘れが一番ありがちな取りこぼしです）。
i18n のキーを足したときは ja / en / ko の 3 ファイルすべてに足します。

今どこまで進んでいるかは **[docs/STATUS.md](docs/STATUS.md)** にまとめてあります。
