# 公式画像を取り込む手順

エージェントのアイコンとマップを、Riot の公式画像に差し替える手順です。
**フォルダ移動やコマンドの暗記は要りません。** ファイルを画面にドラッグするだけです。

所要時間はおよそ 15 分（うち Node.js のインストールが 5 分）。

---

## 全体の流れ

```
[1] Node.js を入れる     … 1 回だけ。次回以降は不要
[2] コードをダウンロード  … ZIP を展開するだけ
[3] コマンドを 2 回実行   … ドラッグ＆ドロップで入力
[4] 確認                … index.html を開く
[5] （任意）GitHub に戻す … オンライン版にも反映したい場合
```

---

## [1] Node.js を入れる

https://nodejs.org/ja を開き、**「推奨版（LTS）」**をダウンロードします。

インストーラーを起動したら、あとは **「次へ」→「次へ」→「インストール」** で終わりです。
設定を変更する必要はありません。

> すでに入っている場合はこの手順を飛ばしてください。バージョンが古いと
> ツールが「Node.js 18 以上が必要です」と教えてくれるので、その時に入れ直せば大丈夫です。

---

## [2] コードをダウンロードする

次のリンクを開くと ZIP のダウンロードが始まります。

https://github.com/longcape/claudeamazon/archive/refs/heads/claude/valorant-tactical-setup-card-iiiog3.zip

> **なぜ普通のダウンロードではダメか**
> このリポジトリはコードが作業ブランチにしか入っておらず、
> トップページから普通にダウンロードすると中身が空になります。
> 上のリンクはブランチを指定済みなので、そのまま使ってください。

ダウンロードした ZIP を**展開**します。

- **Windows** — ZIP を右クリック →「すべて展開」
- **Mac** — ZIP をダブルクリック

展開先はデスクトップなど、後で見つけやすい場所にしてください。
`claudeamazon-claude-valorant-tactical-setup-card-iiiog3` という長い名前のフォルダができます。

その中を開くと、こうなっていれば成功です。

```
├── index.html      ← これが見えていれば正解
├── build.js
├── assets/
├── docs/
└── tools/
```

---

## [3] コマンドを実行する

### 3-1. 黒い画面を開く

- **Windows** — キーボードの `Windowsキー` を押し、`cmd` と入力して Enter
- **Mac** — `command + スペース` を押し、`ターミナル` と入力して Enter

どこで開いても構いません。フォルダを移動する必要はありません。

### 3-2. 1 つ目のコマンド

開いた画面に、**半角で `node` と入力し、そのあとに半角スペースを 1 つ**入れます。

```
node 
```

次に、さきほど展開したフォルダの中の `tools` フォルダを開き、
**`fetch-assets.mjs` というファイルを、黒い画面の中へドラッグ＆ドロップ**します。

ファイルの場所が自動で入力されます。こうなります。

```
node C:\Users\あなた\Desktop\claudeamazon-...\tools\fetch-assets.mjs
```

この状態で **Enter** を押します。

数十秒かかります。次のように表示されれば成功です。

```
data.js のエージェント 29 体 / マップ 12 種を対象にします
  agent  jett       28 KB
  agent  phoenix    31 KB
  ...
  map    ascent     412 KB
  ...
✓ 29 体のアイコンと 12 枚のミニマップを取り込みました
```

### 3-3. 2 つ目のコマンド

同じ要領で、今度は `build.js` をドラッグします。

```
node 
```
と入力してから、フォルダ直下の **`build.js`** をドラッグ＆ドロップして **Enter**。

```
dist/valorant-tactical-setup-card.html  ○○○ KB
dist/artifact-body.html                 ○○○ KB
```

と出れば完了です。

---

## [4] 確認する

フォルダの中の **`index.html` をダブルクリック**してください。
ブラウザでアプリが開きます。

エージェント選択画面（味方スロットをクリック）を開いて、
**六角形のアイコンが顔写真に変わっていれば成功です。**

---

## [5] （任意）オンライン版にも反映する

手順 [4] までで、**あなたの PC 上のアプリ**は公式画像になります。
GitHub 上のコードや共有用のページにも反映したい場合は、生成されたファイルをアップロードします。

アップロードするのは次の 3 つです。

```
assets/img/agents/     ← 29 個の PNG
assets/img/maps/       ← 12 個の PNG
assets/js/official-assets.js
```

**GitHub の画面から入れる方法**（コマンド不要）

1. https://github.com/longcape/claudeamazon を開く
2. 画面上部のブランチ選択で `claude/valorant-tactical-setup-card-iiiog3` を選ぶ
3. **Add file** → **Upload files** をクリック
4. 上の 3 つをドラッグ＆ドロップ（フォルダごとドラッグできます）
5. 下部の **Commit changes** を押す

---

## うまくいかないとき

| 表示されたもの | 対処 |
| --- | --- |
| `'node' は、内部コマンドまたは外部コマンド...` | Node.js が入っていません。手順 [1] へ |
| `Node.js 18 以上が必要です` | Node.js が古いです。https://nodejs.org/ja から入れ直してください |
| `valorant-api.com に接続できませんでした` | 会社や学校の回線だと遮断されていることがあります。自宅の回線かスマホのテザリングで試してください |
| `Cannot find module` | ドラッグしたファイルが違います。`tools` フォルダの中の `fetch-assets.mjs` か確認してください |
| 画像が変わらない | 手順 [3-3] の `build.js` を実行し忘れていないか確認してください。ブラウザの再読み込み（`Ctrl + F5`）も試してください |

---

## このツールが何をしているか

1. `assets/js/data.js` からエージェントとマップの一覧を読む
2. valorant-api.com（Riot の公式アセットを配信しているサイト）から画像を取得し `assets/img/` に保存
3. `assets/js/official-assets.js` を書き出し、アプリが公式画像を使うようにする

**おまけ**: アプリに未登録のエージェントが API 側にあると警告します。
新エージェント実装時の取りこぼしを、このツールで検出できます。

```
⚠ data.js に未登録のエージェントが API 側にあります:
   ○○ (デュエリスト)
```

## 画像の利用について

Riot は「Legal Jibber Jabber」で二次利用を認めており、**収益化も条件つきで許可**しています。

| 条件 | 内容 |
| --- | --- |
| 登録 | [Developer Portal](https://developer.riotgames.com/) に製品登録し、ステータスが Approved か Acknowledged |
| 無料枠 | プレイヤー向けの無料枠が必須。**そこに広告を入れることは明示的に許可されている** |
| 課金 | 課金する場合、コンテンツが transformative（新しい洞察を付加したもの）であること |
| 禁止 | 暗号通貨・ブロックチェーン・NFT は不可 |
| 表示 | 「Riot Games の承認を受けたものではない」旨の免責表示を見やすい場所に掲示 |

本アプリの相性判定と AI 寸評は、構成から新しい洞察を生成しているため
transformative の定義に当てはまります。

なお本アプリは**プレイヤーの試合データを一切取得していません**（すべて手入力）。
そのため Riot Sign On (RSO) による同意フローは不要で、要件は静的アセットの利用のみです。
