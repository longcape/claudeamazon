# 公式画像を取り込む手順

エージェントのアイコンとマップのミニマップを、Riot の公式画像に差し替える手順です。
**プログラミングの知識は要りません。** 決まった文字を 3 回打ち込むだけです。

やらなくてもアプリは問題なく動きます（固有色のアイコンと簡易マップ図が使われます）。

---

## 用意するもの

- インターネットに繋がった PC（Windows / Mac どちらでも）
- **Node.js**（無料）… まだ入っていなければ https://nodejs.org/ja から
  「推奨版（LTS）」をダウンロードしてインストールしてください。
  インストーラーは「次へ」を押していくだけで終わります。

---

## 手順

### 1. リポジトリを PC に持ってくる

GitHub のページを開き、緑色の **Code** ボタン → **Download ZIP** を選びます。
ダウンロードした ZIP を右クリックして展開してください。

（`git` を使い慣れている場合は `git clone` でも構いません）

### 2. ターミナルを開く

「ターミナル」は文字でパソコンに指示を出すための画面です。

| OS | 開き方 |
| --- | --- |
| **Windows** | 展開したフォルダを開き、アドレスバーに `cmd` と打って Enter |
| **Mac** | 展開したフォルダを右クリック →「フォルダに新規ターミナル」 |

> Mac で右クリックメニューに出てこない場合は、
> システム設定 →「デスクトップとDock」→「サービス」から
> 「フォルダに新規ターミナル」にチェックを入れてください。

### 3. コマンドを 2 行打ち込む

開いた画面に、次の 1 行目を貼り付けて **Enter**。

```
node tools/fetch-assets.mjs
```

数十秒かけて画像をダウンロードし、こう表示されれば成功です。

```
  agent  jett       28 KB
  agent  phoenix    31 KB
  ...
✓ 29 体のアイコンと 12 枚のミニマップを取り込みました
```

続けて 2 行目を貼り付けて **Enter**。

```
node build.js
```

これで完了です。`index.html` をダブルクリックして開くと、公式画像に変わっています。

---

## 単一ファイル版にも公式画像を入れたい場合

配布用の 1 枚の HTML（`dist/valorant-tactical-setup-card.html`）にも
公式アイコンを埋め込みたい場合は、1 行目を次に変えてください。

```
node tools/fetch-assets.mjs --inline
```

ファイルサイズは大きくなりますが、そのファイル 1 つで完結します。

---

## うまくいかないとき

| 表示されたもの | 意味と対処 |
| --- | --- |
| `node は、内部コマンドまたは外部コマンド...` | Node.js が入っていません。手順の「用意するもの」からインストールしてください |
| `Node.js 18 以上が必要です` | Node.js が古いです。https://nodejs.org/ja から入れ直してください |
| `valorant-api.com に接続できませんでした` | 会社や学校の回線だと外部通信が制限されていることがあります。自宅の回線やスマホのテザリングで試してください |
| `data.js に const AGENTS = が見つかりません` | フォルダの場所が違います。`index.html` があるフォルダでターミナルを開いてください |

## このツールが何をしているか

1. `assets/js/data.js` からアプリが持っているエージェントとマップの一覧を読む
2. valorant-api.com（Riot の公式アセットを配信しているコミュニティ運営のサイト）から
   対応する画像をダウンロードし、`assets/img/` に保存する
3. `assets/js/official-assets.js` を書き出して、アプリが公式画像を使うようにする

**おまけ**: API 側にあってアプリに未登録のエージェントがいると警告を出します。
新エージェントが実装されたとき、このツールを叩けば取りこぼしに気づけます。

```
⚠ data.js に未登録のエージェントが API 側にあります:
   ○○ (デュエリスト)
```
