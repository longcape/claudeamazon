# 公開・収益化と Riot の規約

このアプリは Riot Games の資産（エージェント画像・スキルアイコン・ミニマップ・
スパイク・名称）を使っている。公開するときに何が要るかの整理。

> 法律の専門家による助言ではない。判断の材料であって、最終的には
> 原文を読み、必要なら専門家に確認すること。原文は英語版が正。

---

## 前提: 個別の許可は要らない

Riot は **Legal Jibber Jabber** というファンプロジェクト向けの方針を公開しており、
条件を満たす限り**事前の申請や個別の許可なく**アセットを使ってよいことになっている。
「まず許可を取りにいく」必要はない。

ただし条件がある。

---

## 無料で公開する場合

満たすべきものは主に次の 3 つ。

### 1. 指定された文言を掲示する（**文言が決まっている**）

```
[プロジェクト名] was created under Riot Games' "Legal Jibber Jabber" policy
using assets owned by Riot Games. Riot Games does not endorse or sponsor
this project.
```

自分の言葉で「Riot とは関係ありません」と書くのでは条件を満たさない。
**この文のとおりに掲示する。**

このアプリでは `index.html` の `.app-foot` に、指定どおりの英文を
言語設定に関係なく常に出している。その下に各言語の訳を添えているが、
訳は読みやすさのための補助で、指定文言の代わりではない。

### 2. 公式だと誤解させない

- プロダクト名やドメインに Riot / VALORANT を含めない
- Riot のロゴや公式のブランド表現を、自分のサービスの看板として使わない
- 「公式ツール」「公認」と読める表現をしない

このアプリの名前は `VALORANT TACTICAL SETUP CARD` で、**VALORANT を含んでいる**。
無料公開の範囲では通っている例が多いが、収益化する段階では
名前から VALORANT を外すことを検討した方が安全。

### 3. Riot に権利が渡ることを受け入れる

この方針でファンプロジェクトを作った時点で、Riot がそのプロジェクトを
無償・非独占・取り消し不能・再許諾可の条件で利用・改変・配布できることに
同意したことになる。クレジット表記も対価も承認も不要という内容。

自分の作ったものが将来まるごと使われうる、という前提を飲めるかどうか。

## 収益化する場合

無料公開の条件に**加えて**、次が要る。

| 要件 | 内容 |
| --- | --- |
| **Developer Portal への登録** | プロダクトを登録し、**Approved** の状態にする |
| **無料枠の提供** | 課金なしで使える層を必ず用意する。広告付きでもよい |
| **課金するなら transformative であること** | Riot のデータをそのまま見せるだけのものに課金しない |

### やってはいけないこと

- 賭博・ベッティングの機能
- Riot のプロパティ内（ゲーム内・ロード画面・Riot クライアント）への広告掲載
- ゲームプレイの模倣・複製にあたるもの

### 認められている集金方法

サブスクリプション / 寄付 / クラウドファンディング / 広告。

### このアプリの場合

- **課金要素**: 戦術の登録数に上限を設けて有料で解放する案が出ている。
  無料枠は必須なので、`config.js` の `TACTIC_LIMIT_FREE` を 0 より大きくして
  無料でも使える形にすること（現在は 0 = 無制限）。
- **transformative か**: 戦術の登録・推奨スコア・相性判定・配置盤は
  Riot のデータをそのまま見せるものではなく、利用者が作った情報が主体なので
  条件は満たしやすい。ただし判断するのは Riot。
- **Riot Games API は使っていない**。試合データやプレイヤー情報を取っていないので、
  API キーや RSO（Riot Sign On）の審査は関係ない。画像は
  valorant-api.com（Riot の公式配信ではなくコミュニティのミラー）から取っている。
  アセットの権利は Riot にあるので、扱いは Legal Jibber Jabber の範囲。

## まとめ

| やりたいこと | 必要なこと |
| --- | --- |
| 無料で一般公開 | 指定文言の掲示・公式と誤解させない・権利許諾を受け入れる。**申請は不要** |
| 広告や課金を入れる | 上記に加えて Developer Portal 登録（Approved）と無料枠 |
| 賭博要素を入れる | 不可 |
