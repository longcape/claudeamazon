# はじめてのユーザーテスト

公開ページ（https://longcape.github.io/claudeamazon/）を、説明なしで初めて使う人に
触ってもらうときの手順と、見るところ・聞くことをまとめたもの。

**目的は「使えるかどうか」を知ることで、感想を集めることではない。**
説明を足したくなっても、テスト中は口を出さない。詰まった場所がそのまま答えになる。

---

## 頼む前にこちらでやること

- [ ] Supabase が止まっていないか（無料プランは使われないと自動で止まる）。
      公開ページのコミュニティを開いて「まだ投稿がありません」か投稿一覧が出ればよい。
      「読み込めませんでした」なら止まっている
- [ ] 公開ページが最新の内容で出ているか（GitHub の Actions が success）
- [ ] 回答の受け皿（フォーム）の URL が用意できているか

## テストしてもらう人へ渡すもの

URL と、次の一文だけ。操作の説明はしない。

> VALORANT の試合で使うツールを作りました。説明なしで触ってみて、
> 分からなかったところを教えてください。PC でもスマホでも構いません。

できれば 2 回に分ける。1 回目は何も頼まずに自由に触ってもらい、
2 回目に下の「やってほしいこと」を 1 つずつ頼む。

### やってほしいこと（2 回目）

1. 次の試合で使う戦術を 1 つ作ってください
2. 作った戦術に、エージェントの立ち位置を描いてください
3. 作ったものが消えないように保存してください
4. ほかの人の戦術を見て、よさそうなものを自分用に取り込んでください
5. 自分の戦術をみんなに公開してください
6. 気になる投稿に「いいね」を付けてください
7. 問題のある投稿を見つけたつもりで、通報してみてください

## 見るところ（チェックリスト）

各項目で「迷わずできた / 迷ったができた / できなかった」を記録する。
**できなかった場所と、どこで手が止まったか**がいちばん価値のある記録。

### 最初の画面

- [ ] 何をするアプリか、最初の画面で分かったか
- [ ] 最初に何を押せばいいか分かったか
- [ ] 上に出る案内を読んだか、読まずに閉じたか
- [ ] サンプルの戦術を自分のものと勘違いしていないか

### 戦術カード

- [ ] 戦術の追加まで迷わずたどり着けたか
- [ ] 「配置を編集」で盤面に置けたか。消し方が分かったか
- [ ] エージェントを 5 人ずつ選ぶ理由が分かったか（マッチ開始に必要）
- [ ] 「マッチ開始」を見つけられたか（画面のいちばん下にある）

### 保存

- [ ] 何もしなくても自動で保存されていると分かったか
- [ ] 「☁ クラウド」をログインしないと使えない保存だと理解できたか
- [ ] 保存のために、わざわざログインしようとしなかったか

### コミュニティ

- [ ] 「コミュニティ」が何のためのタブか分かったか
- [ ] 投稿の仕方が分かったか
- [ ] 投稿すると何が公開されるか、投稿前に分かったか
- [ ] 検索・いいね・通報が、説明なしで使えたか
- [ ] ログインしなくても投稿できることが分かったか

### スマホ

- [ ] 画面が横にはみ出していないか
- [ ] エージェント選択が押せたか
- [ ] 配置盤で置く・動かす・消すができたか
- [ ] 文字が小さすぎて読めない場所はなかったか

### 操作の途中で

- [ ] 再読み込みしても、入れた内容が残っていたか
- [ ] ブラウザの「戻る」で意図しない画面に行かなかったか
      （このアプリは 1 画面なので、戻るとサイトから出る）
- [ ] 同じページを 2 つのタブで開いて、両方で編集していないか
      （後から保存した方で上書きされる。後述の「分かっている弱点」）

### エラー

- [ ] エラーが出たとき、利用者向けの文言だったか（英語の技術的な文が出ていないか）
- [ ] 成功したかどうかが分かったか（右下に出る短いメッセージ）

## 聞くこと（テストの後）

1. 何をするアプリか、すぐに分かりましたか（分かった / 少し迷った / 分からなかった）
2. いちばん分かりにくかった場所はどこですか
3. 使わなかった機能はありますか。なぜ使わなかったですか
4. あったらいいと思った機能はありますか
5. おかしな動きやエラーはありましたか。何をしたときですか
6. 使ったのは PC ですか、スマホですか
7. 使ったブラウザは何ですか（Chrome / Safari / Edge / その他）

---

## 分かっている弱点（テストで出ても想定内）

- **同じページを 2 つのタブで開くと、後から保存した方で上書きされる。**
  タブ同士で内容を合わせる仕組みが無い。1 つのタブで使う前提
- **スマホでは「マッチ開始」までの縦のスクロールが長い**（マップ・10 人分の枠・戦術の一覧の下）
- 配置盤の進行ルートは、スマホでは 1 本ずつ消せない（「すべて消去」でまとめて消す）
- 戦術の種類（EXECUTE / FAST / STACK など）が英語のまま
- Supabase の無料プランは、しばらく使われないと止まる。止まるとコミュニティとログインが使えない
